# 📁 Интерактивный справочник ломбардов

Онлайн-справочник по официальному Государственному реестру ломбардов Банка России. Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/lombard-registry/](https://prog815.github.io/lombard-registry/)

Этот справочник — для заёмщиков, юристов, комплаенс-специалистов, аналитиков финансового рынка и сотрудников служб безопасности. Главная задача — помочь быстро проверить, числится ли ломбард в реестре Банка России и **совпадает ли сайт, на котором предлагают услуги, с адресом, указанным в реестре**.

## Что кодирует реестр ломбардов

**Государственный реестр ломбардов** — официальный перечень ломбардов, зарегистрированных Банком России. Он отвечает на вопросы: **«Законно ли работает этот ломбард?»**, **«Совпадает ли его сайт с указанным в реестре?»** и **«Не исключён ли он из реестра?»**.

В текущем снимке справочника содержится **4 031 запись**, из которых:
- **1 799 действующих** организаций;
- **2 232 недействующих** (исключённых из реестра).

В отличие от реестра страховых компаний, у ломбардов **плоская структура** — одна организация, одна запись в реестре. Карточка содержит:
- ОГРН (используется как уникальный идентификатор), ИНН;
- Полное и сокращённое наименование;
- Адрес, указанный в ЕГРЮЛ;
- **Официальные сайты** (полные URL) и нормализованные **домены** (для поиска);
- Контактные телефоны и электронную почту;
- Дату внесения в реестр и **дату исключения** (для недействующих).

> **Важно про другие финансовые организации.** Этот реестр содержит только ломбарды. Если вам нужно проверить банк, микрофинансовую организацию (МФО), паевой инвестиционный фонд или страховую компанию, используйте соответствующие разделы на сайте Банка России или другие справочники экосистемы.

## Для кого и зачем

Справочник пригодится, если вам нужно:
- **проверить ломбард перед сдачей имущества** — убедиться, что компания легальна и её сайт совпадает с официальным;
- отличить настоящий ломбард от мошеннического сайта-двойника;
- узнать, действует ли компания сейчас или уже исключена из реестра (с указанием точной даты исключения);
- найти ИНН или ОГРН компании для сверки залоговых билетов и документов;
- отфильтровать рынок по статусу (Действующий / Недействующий).

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти».
- **Поиск по реквизитам и домену.** Введите название компании, ОГРН, ИНН, адрес сайта, телефон или email. **Поиск по домену — главная фича**: достаточно ввести `lombard.ooo`, чтобы найти карточку компании.
- **Фильтр по статусу.** Выпадающий список по **Статусу** (Действующий / Недействующий) позволяет мгновенно сузить выборку. По умолчанию показываются только действующие.
- **Копирование в один клик.** Клик по бейджу с ОГРН копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Бейджи статуса и дата исключения.** Цветной бейдж показывает, действует ли компания. У недействующих выводится **красный блок с точной датой исключения** из реестра (в отличие от МФО, где дата в выгрузке отсутствует).
- **Прямые ссылки на сайты.** Клик по чипу с URL сайта открывает его в новой вкладке.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` формирует полный текст с реквизитами компании и ссылкой на карточку.
- **Прямые ссылки на карточки.** Каждую компанию можно передать через `?code=…` в адресе (по ОГРН).
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в тексте карточки.

## Примеры запросов

- `Кристалл` — найдёт карточку ООО "Ломбард "Кристалл"".
- `1023402977058` — откроет карточку компании по её ОГРН.
- `lombard.ooo` — найдёт компанию по домену сайта (главная фича).
- `0277049817` — найдёт ломбард по ИНН (в том числе с ведущим нулём, например, "Уфимский ломбард").
- `Городской` — найдёт все компании с таким словом в названии.
- `8800` — найдёт все компании с таким номером в телефонах.

**Популярные фильтры:**
- **Действующий** — организации, имеющие право осуществлять ломбардную деятельность (1 799 записей);
- **Недействующий** — организации, исключённые из реестра (2 232 записи).
